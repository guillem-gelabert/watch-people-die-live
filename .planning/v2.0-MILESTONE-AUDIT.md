## The two blockers, and what fixing them showed

### INT-01 — the UK's real GBD pyramids were unreachable → resolved

GBD publishes UK subnational units as NUTS-2, so `data/subnational-age-sex.json` emitted
`nuts2:UKC1`… while `build-region-keys.ts` keyed every UK cell `adm1:GBR-nnnn`, because it derived
its NUTS-preferring country set from `subnational-cdr.json` — which has no `GBR`, the UK having
stopped reporting to Eurostat. **0 of 41 keys joined.** All 226 assigned UK cells silently used the
derived tier instead of the measured one, at 1.09% of world expected deaths, and no output anywhere
said so.

The rule was never "mirror `subnational-cdr.json`"; it is "express every key space a consumer joins
against". Fixed accordingly, and the fix was verified at three depths because only the third is
what a reader sees:

- 33 of 41 keys now join (the 8 that don't are metropolitan NUTS-2 regions smaller than a
  0.5° cell — the same resolution limit that costs IND 1 key and PHL 5);
- 217 of 226 assigned UK cells resolve tier 0, carrying **99.96%** of UK expected death weight;
- the UK's cells span **2 archetypes, 11.08pp apart**, where all 227 previously shared one — so the
  fix survives the k-means quantisation rather than being real only at the join.

Two guards so it cannot return silently: the build throws when a whole country's tier-1 key set
joins nothing (warns per key, since single misses are legitimate), and
`scripts/build-age-sex-cells.test.ts` pins the invariant against the committed files. Both were
verified to fail with the fix reverted and pass with it applied.

### INT-02 — 04-06's entire artifact was dead → resolved

`data/eurostat-regional.json` was 1.77 MB, committed, and read by nothing, while its SUMMARY called
it "a build-time validation input, like `observed-regional-age-sex.json`". Its `ageSex` layer turned
out to be exactly that, on the same nine bands, so the only thing in the way was the hardcoded
ISO-3166-2 → `adm1_code` join in `scoreAgainstObserved()`.

Wired: 271 NUTS-2 regions across 34 countries, 3.79pp mean error against 4.02pp for a flat national
pyramid, beating the baseline in 15 of 34 countries. The interesting numbers are the two tier-0
countries — **ITA 1.89pp vs 3.05pp, POL 1.51pp vs 3.62pp** — which is independent evidence that the
GBD regional join INT-01 restored is worth restoring. The tier-1 derived estimator is closer to a
wash in small European countries, and the five where it loses (DNK, HRV, SVN, GRC, LVA, all by
0.1–0.3pp) are named in the build log rather than averaged away.

Note what this could *not* do: Eurostat has no UK rows at all, so it cannot validate the UK fix
itself. ITA and POL test the same mechanism, which is the honest version of the claim.
