**Status:** ✅ SHIPPED 2026-06-29

**Total Plans:** 5

## Overview

The v1 MVP: a shared foundation that touched both project features — real cause data and an honest
methodology for Personas; social sharing, a public roadmap page, and publishing as Shared product
surfaces — without yet splitting into the two independent tracks that v2 forks into.

Phases 1-3 were declared complete on 2026-06-29 but never formally archived. This archive was
written retroactively on 2026-08-28 during the v2.0 milestone close, from the ROADMAP.md phase
details and the five SUMMARY.md files, all of which were still intact.

## Phases

### Phase 1: Cause Fidelity and Methodology

**Goal**: The deaths feed uses full IHME-derived cause distributions when available, and the public methodology accurately explains the current data fidelity.
**Feature:** Personas (cause data) + Shared (methodology)
**Mode:** mvp
**Depends on**: Nothing (first phase)
**Requirements**: [DATA-01, DATA-02, DATA-03, DATA-04, METH-01, METH-02, METH-03]
**Plans**: 2 plans

**Success Criteria** (what must be TRUE):

1. `data/causes.json` exists and can be loaded by the existing persona pipeline.
2. The cause build workflow is documented and repeatable from a GBD CSV source.
3. Missing or incomplete cause data still falls back without breaking the globe or feed.
4. `/methodology` accurately describes mortality, density, age/sex, cause, geolocation, and representative-identity caveats.

Plans:

- [x] 01-01: Build and verify real cause data
- [x] 01-02: Update methodology and fallback explanation

**Delivered:**

- Generated and verified an IHME-derived global, sex-specific `data/causes.json` compatible with the existing persona pipeline.
- Updated methodology and developer documentation so public claims match the shipped global, sex-specific all-ages IHME cause layer.

## Milestone Summary

**Decimal Phases:** None. Phases 1-3 ran in sequence with no insertions.

**Key Decisions:**

- Cause data sourced from IHME GBD rather than a hand-built table — repeatable from a documented CSV workflow.
- The methodology page is written to match the shipped data, not the intended data. When 01-01 shipped a global, age-flat, sex-specific layer, 01-02 said so rather than describing the target state. This became the project's standing convention.
- `/roadmap` separates shipped realism layers from planned ones, so the public page cannot overstate fidelity.
- Web-first, no native app, no accounts, no persistent analytics — recorded in REQUIREMENTS.md Out of Scope and never revisited.

**Issues Resolved:**

- The deaths feed no longer falls back to a placeholder cause distribution.
- Shared links previously carried no preview metadata at all.

**Issues Deferred:**

- All seven `REAL-*` realism layers deferred to v2 rather than blocking the MVP.
- `ENG-01` / `ENG-02` (test runner, frontend module split) deferred — the test runner arrived later via Vitest outside a phase.

**Technical Debt Incurred:**

- `PUB-01` closed as **Partial** — production URL smoke check pending a Railway link. Still outstanding at the v2.0 close on 2026-08-28.
- The v1.0 cause layer was global and age-flat (`coverage.age: "all_ages_repeated_across_bands"`), so only 12 of 140 shipped cause labels were reachable and infant personas drew adult causes. Not recognised as debt at the time — discovered on 2026-07-31 and fixed in v2.0 Phase 4.
