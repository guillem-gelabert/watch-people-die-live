<objective>
Fix the block-math (`$$...$$`) and pseudo-code tiles rendering as near-white boxes on dark-sky
sections. Root cause (already diagnosed): both `.roadmap-code` and `.roadmap-math` paint
`background: var(--ink)`, and `--ink` is the per-section *text* colour, not a fixed dark tone —
`skinFromSky` sets it to `#ffffff` for any sky with relative luminance < 0.2 (the two sections
that actually contain block math, `first-light` (#2b1c3a) and `back-to-the-globe` (#000000), are
both in that bucket).

Purpose: restore the tiles to their intended "dark ink well" look on every sky, without touching
the hard-coded light-grey text that already sits correctly on a dark tile.

Output: a new `--ink-tile` palette token (guaranteed dark for every sky) generated in
`app/roadmap/palette.ts`, consumed by `.roadmap-math` and `.roadmap-code` in
`app/roadmap/roadmap.css`, with a passing unit-test proof and an in-browser confirmation via
Playwright MCP.

working tree (see `git status`). Every `git add` in this plan MUST be scoped to the exact three
files listed in `files_modified` above — never `git add -A` or `git add .`.

From app/roadmap/palette.ts (skinFromSky, ~line 154 — full current body):
```typescript
export function skinFromSky(sky: Rgb): Skin {
  const L = relativeLuminance(sky);
  const dark = L < 0.2;
  const paperRGB = mixRgb(sky, WHITE, dark ? 0.11 : 0.82);
  const inkRGB: Rgb = dark ? [...WHITE] : [...INK];
  const dataRGB = toLuminance(sky, dark ? 0.3 : 0.12);
  const hiRGB = toLuminance([255 - sky[0], 255 - sky[1], 255 - sky[2]], 0.18);
  const base = { dark, paperRGB, inkRGB, dataRGB, hiRGB, paper: rgbCss(paperRGB) };

  if (dark) {
    return {
      ...base,
      tile: mix(sky, WHITE, 0.16),
      tileMuted: mix(sky, WHITE, 0.09),
      tileOpen: mix(sky, WHITE, 0.26),
      ink: "#ffffff",
      body: mix(sky, WHITE, 0.88),
      mute: mix(sky, WHITE, 0.72),
      rule: "rgba(255,255,255,.26)",
    };
  }
  const m = L < 0.36 ? 0.9 : L < 0.5 ? 0.8 : 0.7;
  return {
    ...base,
    tile: mix(sky, WHITE, 0.58),
    tileMuted: mix(sky, WHITE, 0.4),
    tileOpen: mix(sky, WHITE, 0.84),
    ink: "#1d1822",
    body: mix(sky, INK, 0.94),
    mute: mix(sky, INK, m),
    rule: "rgba(29,24,34,.24)",
  };
}
```
`INK` (module-level const, line 42) = `[29, 24, 34]`. `mix(c, t, a)` = `rgbCss(mixRgb(c, t, a))`,
i.e. moves `a` of the way from `c` toward `t`.
